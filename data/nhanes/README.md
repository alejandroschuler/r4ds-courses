# Course datasets

Everything in this directory is generated by [`../build_nhanes_data.R`](../build_nhanes_data.R).
Run it from the repo root to rebuild:

```
Rscript data/build_nhanes_data.R
```

The script is deterministic, so a rebuild reproduces every file byte for byte. It caches the
downloaded source files in `source/` (git-ignored); delete that directory to re-download.

## Sources

| Source | Used for |
|---|---|
| [NHANES 2017-2018](https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/default.aspx?BeginYear=2017) component files (`DEMO_J`, `BMX_J`, `BPX_J`, `TCHOL_J`, `HDL_J`, `GHB_J`, `GLU_J`, `DIQ_J`, `SMQ_J`, `PAQ_J`, `SLQ_J`, `HSQ_J`, `RXQ_RX_J`) | everything participant-level |
| NHANES `DEMO` files for all ten cycles, 1999-2000 through 2017-2018 | `nhanes_cycle_counts.csv` |
| [BRFSS prevalence data, 2022](https://data.cdc.gov/Behavioral-Risk-Factors/Behavioral-Risk-Factor-Surveillance-System-BRFSS-P/dttw-5yxu) | `state_health.csv` |

NHANES is a public-use dataset with no restrictions on redistribution. Codes have been
translated into readable labels (`RIAGENDR` 1/2 becomes `male`/`female`, and so on) and
variables renamed, so the CSVs can be read without the NHANES codebook open.

## Measured vs. simulated

Every measurement, lab value, questionnaire response, drug name, and state prevalence comes
straight from the source files.

Four things are simulated, because NHANES deliberately does not release them:

- `session_id`, `session_date`, `session_type`, and `center_id` in `nhanes_sessions.csv`,
  `nhanes_exams.csv`, and `nhanes_exam_dates.csv`
- `exam_start` and `exam_end` in `nhanes_exams.csv`
- `birth_date` in `nhanes_participants.csv`
- `exam_id`

They are constrained by what NHANES does publish. Each participant's exam falls inside the
real six-month examination window recorded in `RIDEXMON`, sessions land on weekdays in the
true 2017-2018 field period, three sessions run per day, and `birth_date` is back-calculated
from the participant's reported age at exam. They exist so that the date-parsing and
age-calculation exercises have something to work on. Do not read anything into them beyond
that.

`status_code` in `nhanes_exams.csv` is derived rather than simulated: it is 1 when that
component's primary measurement is present for that participant and 2 when it is missing.

## One thing worth knowing about the blood pressure readings

`bp_sys_4` and `bp_dia_4` are missing for 94% of participants, and that is not a data
problem. NHANES takes three readings and only adds a fourth when one of the first three
cannot be obtained, which is why a participant with a fourth reading is almost always missing
their first. Several exercises depend on this.
