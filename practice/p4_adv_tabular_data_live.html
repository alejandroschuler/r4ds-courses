Data Description

We will be working with data from NHANES, the National Health and Nutrition Examination Survey. NHANES has been run by the CDC since the 1960s. Every two years it interviews a nationally representative sample of about 10,000 Americans, brings them into a mobile examination center for a physical exam, and draws blood. We are using the 2017-2018 cycle, which examined 9,254 people.

The public NHANES files are documented here:

Centers for Disease Control and Prevention (CDC). National Center for Health Statistics (NCHS). National Health and Nutrition Examination Survey Data, 2017-2018. Hyattsville, MD: U.S. Department of Health and Human Services, Centers for Disease Control and Prevention. https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/default.aspx?BeginYear=2017

The tables we use here were built from those files by data/build_nhanes_data.R in this repository. The tables are already stored in a subdirectory called “data” placed immediately inside the directory containing this notebook. Note that NHANES does not release exam dates or dates of birth, so the exam_start, exam_end, and birth_date columns are simulated (consistent with each participant’s real reported age and examination period). Every measurement, lab value, and drug name is real.

Inspect the Distribution of Medication Counts by Participant

We will use information from the medications and participants tables to generate a distribution of medication counts per unique participant. We will begin working with the medications table, with which we will group rows by the participant_id column, taking the size of each grouping. For this analysis, we will focus on the number of unique medications taken by each participant; even if the same medication is taken more than once, that medication will be counted only once.

TipShow the answer 
# To identify the number of medications taken by each participant, we only need the `PATENT` and `drug_id` columns of the `medications` table
# For convenience, let's store those columns in their own data frame
med_patient_codes <- df_medication %>%
  select(participant_id, drug_id)

# Remove duplicate records with same values in `participant_id` and `drug_id` columns
med_patient_codes <- med_patient_codes %>%
  distinct()

# TODO: Group the medications table by the `participant_id` column, and take the size of each group
# This will return the number of distinct medications that each participant is taking
med_patient_codes_grouped <- med_patient_codes %>%
  group_by(participant_id) %>%
  summarise("med_count" = n()) %>%
  ungroup()

Keep in mind, participants with zero medications will not appear in the med_patient_codes_grouped table. Recall that the df_participant table includes all participants. We can use the df_participant table to fill in missing participant identifiers in the med_patient_codes_grouped table. Below, we select the participant identifiers from the id column of the df_participant table and merge them with the med_patient_codes_grouped table to create a row for all participants.

You may notice that some rows have a missing value (NA) in the med_count column. These rows correspond to participants without medications, who do not appear in the med_patient_codes_grouped table. When we merged the df_participant and med_patient_codes_grouped tables, the med_count was not available for these rows. We will replace the missing values with zero.

Finally, we can plot the medication counts from all participants using a histogram.

Alternatively, we could pivot the df_medications table so that each column corresponds to a medication drug_id and each row corresponds to a different participant. In this table, use a value of 1 to indicate that the participant corresponding to the row takes the medication corresponding to the column. Use a value of 0 to indicate that the participant corresponding to the row does not take the medication corresponding to the column.

TipShow the answer 
# TODO: Pivot the 'df_medication' table so that rows correspond to participants and columns correspond to codes
medications_pivot <- df_medication %>%
  select(participant_id, drug_id) %>%
  distinct() %>%
  mutate(value = 1) %>%
  pivot_wider(names_from = drug_id, values_from = value, values_fill = 0)

# Display the pivoted medications table
print(medications_pivot)

Identify Younger Participants Taking Many Medications

Our task is to identify participants under 40 years old who are taking “many” medications. We will define “many” medications as five or more medications. This task could be used to identify eligible participants for a clinical trial using existing health records. We will break the task down into four steps.

STEP 1. Using the birth_date column of the df_participant table, identify the age of each participant (in years) on a provided reference date. For help, review the p3_basic_tabular_manipulation notebook.

TipShow the answer 
# Age will be evaluated at January 1, 2023
ref_date <- as.Date("2023-01-01")

# Convert the `birth_date` column in the `df_participant` table to date format
df_participant <- df_participant %>%
  mutate(birth_date = as.Date(birth_date))

# TODO: Create a column called `age (years)` in the `df_participant` table indicating the age of each participant
df_participant <- df_participant %>%
  mutate(`age (years)` = as.numeric(floor(ref_date - birth_date)) / 365.25)

STEP 2. Filter the participants table to include only rows associated with participants under 40 years old. Store this in a data frame called under_40

under_40 <- df_participant %>%
