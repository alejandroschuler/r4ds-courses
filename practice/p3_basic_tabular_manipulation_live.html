Data Description

We will be working with data from NHANES, the National Health and Nutrition Examination Survey. NHANES has been run by the CDC since the 1960s. Every two years it interviews a nationally representative sample of about 10,000 Americans, brings them into a mobile examination center for a physical exam, and draws blood. We are using the 2017-2018 cycle, which examined 9,254 people.

The public NHANES files are documented here:

Centers for Disease Control and Prevention (CDC). National Center for Health Statistics (NCHS). National Health and Nutrition Examination Survey Data, 2017-2018. Hyattsville, MD: U.S. Department of Health and Human Services, Centers for Disease Control and Prevention. https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/default.aspx?BeginYear=2017

The tables we use here were built from those files by data/build_nhanes_data.R in this repository. The tables are already stored in a subdirectory called “data” placed immediately inside the directory containing this notebook. Note that NHANES does not release exam dates or dates of birth, so the exam_start, exam_end, and birth_date columns are simulated (consistent with each participant’s real reported age and examination period). Every measurement, lab value, and drug name is real.

Create New Columns using Existing Columns

Using the mutate function in dplyr and the sapply in base R, create a new column in the participant_ages table called "age_group" with the following values: "minor" if the participant is under 18 years old, "adult" if the participant is between 18 and 65 years old, and "older adult" if the participant is over 65 years old. To support this task, we provide the function get_age_group that takes a numerical age in years and returns the associated age group.

TipShow the answer 
# We will provide a function for identifying age category
# The function accepts a numerical age and returns a string age category
get_age_group <- function(age) {
  if (age < 18) {
    return("minor")
  } else if (age >= 18 && age <= 65) {
    return("adult")
  } else {
    return("older adult")
  }
}

# TODO: Apply the function to the `age` column of `participant_ages` to obtain the age category of each participant
# Hint: Use the `mutate` function in dplyr to define the `age_group` column
# Hint: Use the `sapply` function to apply the `get_age_group` function to the `age (years)` column
participant_ages <- participant_ages %>%
  mutate(age_group = sapply(`age (years)`, get_age_group))

Grouped Summaries

Calculate the average age of participants in the three age groups: "minor", "adult", and "older adult". Use the group_by and summarize functions in dplyr to complete this task.

TipShow the answer 
# TODO: Calculate the average age in each age group
age_group_averages <- participant_ages %>%
  group_by(age_group) %>%
  summarize(
    mean_age = mean(`age (years)`),
  )

# Print the age group averages
print(age_group_averages)
