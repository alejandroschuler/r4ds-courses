Data Description

We will be working with data from NHANES, the National Health and Nutrition Examination Survey. NHANES has been run by the CDC since the 1960s. Every two years it interviews a nationally representative sample of about 10,000 Americans, brings them into a mobile examination center for a physical exam, and draws blood. We are using the 2017-2018 cycle, which examined 9,254 people.

The public NHANES files are documented here:

Centers for Disease Control and Prevention (CDC). National Center for Health Statistics (NCHS). National Health and Nutrition Examination Survey Data, 2017-2018. Hyattsville, MD: U.S. Department of Health and Human Services, Centers for Disease Control and Prevention. https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/default.aspx?BeginYear=2017

The tables we use here were built from those files by data/build_nhanes_data.R in this repository. The tables are already stored in a subdirectory called “data” placed immediately inside the directory containing this notebook. Note that NHANES does not release exam dates or session times, so the exam_start and exam_end columns are simulated (each participant’s exam falls inside their real reported examination period). Every measurement, lab value, and drug name is real.

Import Modules

Specify and Load Data

In this demonstration, we will be working with just one data table containing exam components. This data file is located at data/exams.csv, relative to the directory containing this notebook. Below, we load this table from the CSV file into a data frame.

Format Date/Time information

The exams table includes exam_start and exam_end timestamps denoting the start and end times of each exam component. We format these columns into date/time format using the POSIXct package.

Task 3: Identify the Duration of Each Exam Component

For each exam component, we take the difference between the values in the exam_end and exam_start columns and express the result in units of hours. We store the results in a new column of the exams table called duration_hr.

Plot a Histogram of Component Durations

We visualize the distribution of component durations. Notice, there will be some outliers. To address outliers, we exclude durations greater than four hours from your histogram.

It appears that the durations are recorded in 5 minute intervals, with a minimum component duration of 20 minutes.

Isolate the Exam Components for a Single Participant

We isolate the exam components associated with participant NHANES-100000. To do so, we filter the rows in the exams table to those associated with our participant of interest.

Identify Examination-Center Workload Following a Component

A mobile examination center has a finite amount of time on the road, so knowing how heavily each center is booked matters for planning. We will work through an analysis of the week of work that follows any given component. Given a component, we will implement a function to do the following:

  1. Identify the date one week after the exam_end of the component
  2. Identify all subsequent components run at the same center during that week
  3. Calculate the total examination time booked during that week

Task 8: Summarize the Exam Components and Export to CSV

We generate descriptive statistics summarizing the exam components, and export those summary statistics to a CSV file.

Summary

In this notebook, we worked with date/time data to summarize exam components reported in health records.
