Overview

This course will make you an expert at data I/O, transformation, programming, and visualization in R. We will use a consistent set of packages for these tasks called the tidyverse.

This is not a traditional programming or computer science course. It is meant to be an applied tour of how to actually use R for your data science needs. We also will not cover statistical analysis of data in this course, but the curriculum is a useful prerequisite for subsequent courses on statistics or machine learning.

This course is not graded, nor are there any assignments or homework. The lectures are just to get you started- they will be frequently interrupted by active learning exercises that you will be asked to complete in pairs or small groups. That’s where the real learning will happen!

Prerequisites

No prior experience with R is expected. Those with experience using R will still likely find much of value in this course since it covers a more modern style of R programming that has gained traction in the past decade.

We will use R through the RStudio interface. The easiest way to access RStudio is through the cloud: posit.cloud. It’s fast and easy- just go the link, click “get started” and create an account. Once you’re in, click “new project” near the upper-right and the RStudio interface will open.

Alternatively, you can install R and RStudio on your own computer: Follow this link and click on the appropriate options for your operating system to install R, then do the same to install RStudio.

Learning Goals

By the end of the course, you will be able to:

  • comfortably use R through the Rstudio interface
  • read and write tabular data between R and flat files
  • subset, transform, summarize, join, and plot data
  • write reusable and readable programs
  • seek out, learn, and integrate new packages and code into your analyses

Optional Practice Exercises

These notebooks are optional. Each one walks through a short analysis of NHANES data, the same survey the lectures draw on, and leaves gaps for you to fill in. Look for the ellipses (...) with a TODO comment above them. An answer key is posted next to each exercise.

Each exercise is a Quarto document, saved with a .qmd extension. A Quarto document mixes ordinary prose with chunks of runnable R code, so the explanation of a step sits directly above the code that carries it out. Running the file from top to bottom executes every chunk in order and produces an HTML report with the results and figures dropped in where they belong. RStudio has understood the format since version 2022.07 and ships with everything it needs, so there is nothing extra to install. The Quarto website covers the rest, including the other languages and output formats it can handle.

Downloading the files

Every notebook reads its data from a folder called data that has to sit right next to the notebook, so saving the .qmd by itself will not be enough. The quickest way to get everything into the right places is to paste this into the R console and hit enter:

dir.create("practice/data", recursive = TRUE)
base = "https://alejandroschuler.github.io/r4ds-courses/practice/"

for (f in c("p1_programming_basics.qmd",
            "p2_R_fundamentals.qmd",
            "p3_basic_tabular_manipulation.qmd",
            "p4_adv_tabular_data.qmd",
            "p5_functional_programming.qmd",
            "extra_demo_datatypes.qmd")) {
  download.file(paste0(base, f), file.path("practice", f), mode = "wb")
}

for (f in c("participants.csv", "exams.csv", "medications.csv", "state_health.csv")) {
  download.file(paste0(base, "data/", f), file.path("practice/data", f), mode = "wb")
}

This behaves the same way on posit.cloud as it does on your own computer. It makes a practice folder inside your working directory, drops the six notebooks into it, and puts the four data tables in practice/data. If you want the answer keys on hand too, add _answers before the .qmd in any of the file names above and run it again.

To download by hand instead, click the links in the table and the notebook will save straight to your computer. You still need the four data tables: participants.csv, exams.csv, medications.csv, and state_health.csv. Your browser opens those in a tab rather than saving them, so right-click each one and choose “Save link as”. Put all four in a folder named data next to the notebooks.

On posit.cloud, the Upload button in the Files pane moves files from your computer into your project.

Opening and running a notebook

Look in the Files pane at the lower right of RStudio, click into the practice folder, and click a notebook. It opens in the editor as text and gray code chunks mixed together. Run one chunk at a time with the green triangle at its upper right. The Render button above the editor runs everything from top to bottom and produces an HTML report.

The exercises need a few packages you may not have yet. Install them once with:

install.packages(c("tidyverse", "maps"))
